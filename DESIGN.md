# Interface palette

User-approved colour reference: screenshot supplied November 19, 2026. Sampled solid colours are used directly for the native Streamlit theme in `.streamlit/config.toml`.

| Role | Colour | Use |
|---|---|---|
| Primary | #AFF33E | Primary actions, selection and active controls |
| Background | #020617 | Main application surface |
| Card / inset | #0F172A | Sidebar surface |
| Secondary / muted | #1E293B | Inputs and secondary surfaces, subtle separators |
| Accent | #14532D | Success surface, with light text |
| Destructive | #991B1B | Error surface, with light text |
| Main text | #F1F5F9 | Body text |
| Secondary text reference | #94A3B8 | Reference muted text colour |
| Control border | #64748B | Accessible adaptation of the reference's dark border |

Use navy surfaces to frame the scanned page. Original form images and black-on-white layout previews retain their source colours. Lime identifies primary actions; do not use it for decorative headings. Error and success states include text, never colour alone. Primary action text is near-black for contrast against lime. Native widget focus remains visible.

The reference's #1E293B border is suitable as a subtle separator, but lacks sufficient contrast for an input boundary on the same surface. Interactive borders therefore use the lighter #64748B. No navigation or workflow changes are part of this palette update.
